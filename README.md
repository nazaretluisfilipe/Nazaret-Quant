# Nazaret Quant

Projeto de pesquisa quantitativa voltado à análise de estratégias para ativos negociados na B3.

> **Estado atual deste repositório:** preparação do repositório. O código-fonte do MVP ainda não foi publicado aqui. O arquivo original recebido está sendo separado de dependências, bases de dados e arquivos locais antes da importação.

## Objetivo

Avaliar hipóteses de negociação de maneira reproduzível, com dados históricos, custos realistas, testes cronológicos e critérios de aprovação definidos antes da avaliação final.

## Segurança

- Não realizar operações reais durante a fase de pesquisa.
- Não armazenar credenciais de corretora ou chaves de API.
- Não publicar bases licenciadas ou dados pessoais.
- Não confundir resultados em dados sintéticos com evidência de rentabilidade.

O primeiro marco é restaurar o código do MVP, executar os testes existentes e validar o uso de históricos reais.
